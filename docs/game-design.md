# 游戏设计基线｜像素回响：泰拉试炼

本文件是 Harness 各角色的产品规则与数值基线，来源为用户已确认的
`tasks/prd-pixel-echo-arena.md`。实现时以本文件的数值为准；调整数值必须记录理由并同步
验收基线，不得删除角色机制来降低难度。工程规范见 `docs/patterns-*.md`。

## §3 局流程与状态机

主菜单 → 选角色并阅读技能 → 第 1 波 → 击杀拾取经验 → 暂停选强化 → 继续战斗 →
波间补给 → 第 9 波 Boss → 胜利/死亡结算 → 同角色重开或返回选角。

- 每波开始有 3 秒倒计时；普通波在前 30 秒完成定额刷怪，清空后进入波间，不用
  “到点自动消失”结束。
- 波间显示波次、生命、强化概览；回复最大生命的 15%，不复活死亡角色；Enter 进入下一波。
- 第 3、6 波清空后，额外获得一次机制强化三选一，处理完才允许进入下一波。
- 普通波超过 90 秒时显示残敌方向提示，不传送击杀、不隐藏敌人。
- 生命归零立即结束；先处理本帧伤害和死亡，再处理升级与胜利；与 Boss 同帧死亡记作失败。
- 不允许复活广告、无限拖延刷经验或退出重进重新抽强化。
- 状态机：`menu → character-select → countdown → combat → upgrade / intermission →
  combat → result`。`paused` 保存被暂停前的状态；失焦自动暂停，恢复焦点后需 Enter
  明确继续。菜单与选强化期间不推进敌人、弹体、冷却、持续效果或波次计时。

## §4 操作与选敌

2026-10-19 用户追加：定向技能与当前面向一致，支持八向移动；本节取代旧的全向自动瞄准规则。

| 场景 | 按键 | 行为 |
| --- | --- | --- |
| 战斗 | WASD | 八方向移动，对角线速度归一化 |
| 战斗 | J（可按住） | 沿当前面向按攻击间隔持续普通攻击，允许空射 |
| 战斗 | K | 角色战术技能，每次按下触发一次 |
| 战斗 | L | 角色招牌技能，每次按下触发一次 |
| 战斗 | Space | 按移动方向闪避；静止时沿最近朝向 |
| 战斗 | Tab | 切换前方扇区内提示目标，不改变面向 |
| 菜单/选角/强化 | WASD 或方向键 | 移动焦点；布局边界不跳到无关控件 |
| 菜单/强化/结算 | Enter | 确认焦点项；关闭面板的同一按键不穿透到战斗 |
| 强化 | 1 / 2 / 3 | 移动焦点到对应卡，仍需 Enter 确认 |
| 强化 | R | 使用本局剩余重抽次数；默认每局 2 次 |
| 各界面 | Esc | 暂停/返回；强化不可通过 Esc 跳过 |

- 面向有上、下、左、右及四个斜向共 8 个方向；由 WASD 合成的非零输入更新，斜向向量归一化。松开按键、相反键完全抵消或失焦时保留最后面向，初始朝右；顶墙时也可通过方向输入转身。
- J 和定向 K/L 按每次攻击实际发出的瞬间取当前面向；弹体、扇形中心线与落点均沿该方向，不自动朝目标偏转。已经飞出的弹体不因玩家随后转身而拐弯。
- 无敌人时也可朝面向空射；弹药在实际射出时扣除，不能因未命中返还。近战扇形可挥空，仍消耗攻击间隔。
- 自动选敌只负责面向前方 120° 扇区内的目标提示，不决定弹道；无前方目标就不选，禁止回退全向最近。等距按稳定敌人 ID 排序。
- Tab 仅切换当前前方扇区且射程内的提示目标，不改变角色面向；目标死亡、出射程或转到背后立即取消。射击不依赖目标实体存在。
- 定向地面技能落在当前面向的技能配置距离处，沿施法线遇墙则截断；自身治疗、领域、变身和流形形态切换不需要方向目标。
- 魂灵/流形的新建位置默认在玩家面向前方 40 像素的最近合法空位；召唤物后续按自己的选敌与面向自主作战，不改变玩家面向。
- 普通攻击允许移动施放；不要求玩家一手按方向键瞄准、一手按 JKL、一手按 WASD。
- 闪避持续 0.18 秒、位移 90 逻辑像素、前 0.15 秒无敌、冷却 3 秒；仍受场地墙体阻挡。
  所有角色一致。
- 键盘状态使用物理键位 code；失焦清空按下状态。战斗时 Space/Tab 不滚屏或抢走焦点。
- 设置支持重绑战斗按键；检测重复键位并提示冲突，取消编辑不改变原绑定；提供恢复默认。
- 主菜单、设置、帮助、暂停、选角、三选一和结算均有可见焦点；鼠标只可作为可选便利，
  不得成为必需。

## §5 角色数值与机制

通用约定：

- 使用逻辑像素与秒；角色圆形碰撞半径 12。默认暴击关闭，首版不另做暴击系统。
- 物理伤害 = 原始伤害 × 100 / (100 + 护甲)；法术伤害 = 原始伤害 × (1 − 法抗)；
  真实伤害不受二者影响。最终伤害先扣护盾再扣生命。
- 伤害与生命内部保留小数，HUD 显示向上取整；死亡以实际生命 ≤ 0 判断。
- 百分比同类增益加算，不同类别相乘。技能冷却缩减上限 40%，减伤上限 60%，
  移速最低为基础的 40%。
- 击退、束缚、眩晕分别建状态，不把视觉特效当判定。Boss 免疫强制位移；
  眩晕/束缚转为原持续时间的 30% 减速。
- 所有数值是首轮平衡基线，存集中配置；后续可依据通关记录调整，须记录理由并同步
  验收基线，不可删除角色机制降低难度。

### §5.1 维什戴尔：标记—余震—爆破

- 基础：生命 110，护甲 8，法抗 0，移速 150。
- **J 榴弹**：间隔 0.9 秒，射程 290；命中造成 36 物伤、半径 32 溅射；0.35 秒后同位置
  余震造成 18 物伤。直接命中的主目标附着一层残影。
- **被动 残影**：余震击中有残影的敌人时消耗标记，额外造成半径 42、24 物伤爆炸与
  0.3 秒眩晕；引爆不会再生成余震或残影，禁止无限递归。
- **K 魂灵之影**：冷却 14 秒；在自身附近召唤 12 秒的魂灵，默认最多 1 个，达到上限时
  替换最早生成者；每 1.5 秒给范围 240 内未标记敌人附着残影并减速 20% 持续 1 秒；
  无敌、不挡路，不直接造成伤害。
- **L 爆裂黎明**：冷却 30 秒；接下来 6 发 J 的直接与余震伤害提高 100%、溅射半径提高
  50%，发射间隔 1.1 秒；射出才扣弹药，20 秒后未用弹药失效；HUD 显示剩余弹药。
- 玩法：魂灵提前铺标记，重炮清群；高爆发换取较慢的走位节奏。

### §5.2 阿米娅：连射—回转—奇美拉

- 基础：生命 100，护甲 0，法抗 15%，移速 165。
- **J 源石术式**：间隔 0.4 秒，射程 260，单发 20 法伤。
- **被动 情绪吸收**：每 5 次 J 对敌命中，使 K 当前剩余冷却减少 1 秒；同一发穿透多敌
  只累计一次。
- **K 精神爆发**：冷却 9 秒，0.8 秒内连续发射 6 发、每发 14 法伤，每发沿实际发射时的当前面向；不追踪目标；结束后 0.5 秒不能 J，但可移动和闪避。
- **L 奇美拉**：冷却 30 秒、持续 8 秒；J/K 转为真实伤害且伤害 +60%；结束后 3 秒移速
  −25%、不能 K/L，仍可 J 与闪避。以短暂虚弱改编原作的退场代价，不突然强制结束玩家本局。
- 玩法：用连射加快回转，选择安全时机真伤爆发，然后处理虚弱窗口。

### §5.3 塞雷娅：近身承压—治疗—钙质领域

- 基础：生命 180，护甲 35，法抗 10%，移速 140。
- **J 盾击**：间隔 0.55 秒，70 距离、100° 扇区，造成 26 物伤并击退普通敌人 12。
- **K 急救配置**：冷却 10 秒；自身恢复 40 生命，获得 25 护盾持续 4 秒；治疗不超过生命
  上限，护盾不叠加，取较高剩余量并刷新时间。
- **被动 精神回复**：K 实际恢复生命时，使 L 剩余冷却减少 2 秒；满血施放不触发，
  不因持续治疗递归触发。
- **L 钙质化**：冷却 28 秒、持续 8 秒，跟随自身半径 120；每秒回复自身 8 生命，领域内
  敌人减速 35%、受到法伤 +30%；期间 J 额外造成 10 法伤。后者是让单人防护角色能够
  独立推进的原型改编。
- 玩法：用近距离扇面盾击与治疗稳住阵地，用领域和反击构筑完成输出，而非只能等敌人
  自己死亡。

### §5.4 缪尔赛思：双形态流形—塑形—控制

- 基础：生命 105，护甲 5，法抗 10%，移速 165。
- **J 水弹**：间隔 0.55 秒，射程 250，18 法伤；初始自带一个近战流形。
- **K 塑形**：冷却 6 秒，在近战/远程流形间切换；只有一个主流形，切换保留生命百分比，
  不刷新 L 或治疗。流形死亡时 K 改为重建当前形态，重建后开始 6 秒冷却。
- **近战流形**：生命 90，跟随玩家并攻击 90 范围内敌人，间隔 0.7 秒、16 物伤；命中使
  自身伤害 +2、护甲 +2，最多 5 层，重建清零；受距离更近的近战敌人攻击。
- **远程流形**：生命 60，跟随玩家，射程 230，间隔 0.8 秒、14 法伤；每 8 次攻击生成
  一个持续 5 秒、伤害为主流形 50% 的远程副本，默认最多 1 个副本。
- **L 浅层非熵适应**：冷却 24 秒、持续 6 秒；近战形态每 2 秒将半径 100 普通敌人向
  主流形拉近 35 并眩晕 0.5 秒；远程形态立即刷新已有副本的寿命，主流形与副本命中束缚
  0.5 秒。无主流形时 L 不消耗冷却并提示先重建。
- 跟随不会穿出场地；距离玩家超过 240 时回到身边的空位，不能卡墙；切换至近战移除远程
  副本，避免双形态无成本叠加。
- 玩法：用近战流形承伤聚敌，或远程分裂形成交叉火力；这是受原作复制机制启发的两种
  预置模板，不复制整套英雄系统。

## §6 升级与强化

### §6.1 经验与升级

- 经验由击杀敌人掉落，普通敌人 5、精英 25；经验球吸取半径 55，波次结束自动吸取剩余经验。
- 初始等级 1、最高 9；从等级 n 升至 n+1 需要 `40 + 20 × (n−1)` 点经验，溢出保留，
  满级后不再产生升级弹窗。
- 每次升级最大生命 +5 并回复 5 生命，随后三选一；同时升多级则排队逐个选择，不能遗漏
  或一次选择重复应用。
- 波次结束时顺序：吸取经验 → 处理升级选择 → 第 3/6 波额外机制选择 → 波间补给。
  玩家死亡时不再处理这些奖励。

### §6.2 抽取与重抽

- 普通升级按银/金/棱彩权重 50/35/15 抽取；卡片互不重复，只出通用或当前角色专属卡，
  已满层的不再出现。无有效卡的稀有度移出抽取，剩余权重重新归一化；同稀有度内等概率。
- 第 3/6 波机制选择从当前角色 4 专属卡中选 3 个未拥有的；不足 3 时由未拥有的金色
  通用机制卡补齐，再不足用有效银卡补齐。
- 重抽仅重抽当前 3 张，不改变已获得强化；本局共 2 次。池大小足够时新 3 张排除旧 3 张，
  否则允许交集但同一手不重复。
- 所有抽取使用本局种子与独立奖励随机序列；存档保存已生成的手牌和随机状态，刷新不能刷卡。
- 卡片写明效果、层数上限、适用技能；确认后立即更新实效与构筑清单。不能只改描述或图标。

## §7 场地、敌人与 Boss

- 固定逻辑画面 960×540，场地 1440×960，摄像机跟随玩家且钳制边缘；俯视轻斜视，
  不使用等距地块与复杂高低差。
- 场地为废弃实验训练区：四周墙壁、中央开阔区域、4 个对称短掩体；不能形成封闭死区。
  角色、近战敌人和流形受障碍阻挡，直射弹体命中障碍消失，爆炸不穿墙伤害。
- 出生点距玩家至少 220，提前 0.8 秒红圈提示；不能生成在墙中或屏幕内玩家脚下。
- 普通敌人：追击者（60 HP，接触 8 物伤）；射手（45 HP，每 1.6 秒发射 10 物伤弹）；
  冲锋者（80 HP，预警 0.7 秒后直线冲锋 18 物伤）；重装者（160 HP、护甲 40，缓慢近战
  14 物伤）。
- 敌人接触伤害对玩家共享 0.5 秒受击间隔，防止同帧重叠瞬杀；射弹按独立攻击判定，
  但命中无敌期无伤。
- 第 1/2 波为追击者/射手；第 3 波加入精英冲锋者；第 4/5 波加入普通冲锋者/重装者；
  第 6 波加入精英重装者；第 7/8 波混合。
- 第 1–8 波普通敌人数依次为 12、16、18、22、26、28、32、36，第 3/6 波各额外 1 个精英；
  普通生命倍率 `1 + 0.12×(波数−1)`，伤害倍率 `1 + 0.06×(波数−1)`；精英生命再 ×3，
  伤害 ×1.3。
- Boss「失控实验体」：基础 2600 HP、护甲 20、法抗 15%；扇形弹幕与地面延迟爆破交替。
  生命低于 50% 进入二阶段，增加预警冲锋和每 15 秒召唤 4 个追击者；不复制新的 Boss。
- 弹幕至少保留一个可走位缺口；地面危险预警 ≥0.7 秒；每次攻击都有形状、声音和色彩
  三者中至少两类提示，不靠红绿区分。
- Boss 被击败后清除剩余敌弹与普通敌人，存活玩家进入胜利结算。

## §8 视觉、音效与信息设计

2026-10-19 美术更新：先读取 `docs/character-art-direction.md`，并查看 `docs/references/wisadel-chibi-reference.png`。这两个文件定义当前人物美术基线，替代原来的细长 32×48 人形规格。

- 统一约 1.5–1.8 头身的大头短身 Q 版：短四肢、粗深色描边、大眼睛与夸张表情，重新绘制为原生像素，不直接缩小附件或套马赛克滤镜。
- 维什戴尔以用户参考图的银灰发、呆毛、红黑角、黄橙眼、黑红服装与呆萌/狡黠表情为样板；阿米娅、塞雷娅、缪尔赛思保留各自耳角、发型、装备、配色和技能特点。
- 透明 64×64 帧、统一脚底锚点；美术大头不扩大逻辑碰撞半径 12。正常游戏与 4 倍最近邻预览都要可辨认，禁止裁掉角耳与武器。
- 先由 US-031 替换已有维什戴尔资源与生成流程，其他角色故事复用风格规范而非复用同一张脸；US-025 汇总验收。
- Validator 对人物素材变更必须查看参考图、实际精灵表和场内截图，记录比例/五官/角色辨识度/透明边缘，不接受只验证文件存在。

- 整体是“废墟实验场 + 明亮角色技能”的像素风，不做满屏渐变管理后台。战场优先，
  HUD 只占必要空间。
- 用武器朝向或清晰的八向指示表现实际面向；身体允许复用四向精灵，斜向施法不能与画面指向矛盾。
- 角色采用自行制作的 64×64 像素精灵，使用最近邻缩放；每人具备上/下/左右朝向
  （左右允许镜像），待机、至少 2 帧行走、攻击与受击反馈。
- 四角色必须靠轮廓、发型、装备和技能形态可区分；不能只用圆点、字母、Emoji 或四色
  矩形代表人物。选择页显示与场内一致的大像素预览。
- 维什戴尔红橙炮火与暗色魂灵；阿米娅蓝黑术式与奇美拉高亮轮廓；塞雷娅白橙防护与
  领域边界；缪尔赛思青绿水体与半透明流形。敌方攻击统一暖红警戒纹理，友方效果不得
  遮蔽预警。
- HUD：生命/护盾、等级经验、波次、J/K/L 图标与冷却秒数、闪避冷却、当前目标、
  角色专属资源。数值旁配文字，不只显示图形。
- 强化面板：3 张横排卡片，名称/稀有度/机制/层数与快捷键清楚；背景战场冻结但仍可辨认。
- 命中具备短促闪白、轻微击退或伤害字；大招和强化变化具备可见反馈。屏震可关闭，
  尊重减少动态效果设置。
- 最低支持 1280×720 桌面窗口；1440×900 与 1920×1080 不拉伸像素角色、不截断技能文本。
  普通界面字体不低于 16 CSS px。
- 音效用自行合成或明确可用素材；首个键盘确认后启用音频，设置里能静音。不得依赖外链
  素材或在线字体才能运行。

## §9 存档、结算与边界

- localStorage 保存设置、键位和最近 10 局成绩；同一浏览器无需账号。
- 在波初、波间、生成强化选项、重抽完成及选卡完成时保存续局快照；战斗中刷新从最近
  安全检查点恢复，而不是恢复到刷新前一帧。
- 快照包含角色、生命、等级、经验、已选强化、波次、重抽次数、随机状态、待选手牌与
  剩余奖励队列；不允许刷新重领治疗或强化。
- 波中升级检查点还须保存玩家/敌人/弹体/召唤物的位置、面向与状态、冷却、持续效果与波内时钟；
  恢复后先保持暂停，Enter 才继续。存储数据是可序列化逻辑状态，不包含渲染对象、音频
  或函数。
- 保存采用明确 schemaVersion；损坏或不支持的存档提示原因，允许键盘确认重置本游戏
  存档，不清理其他站点数据。
- 存储不可写时继续本局，但显示“本局无法保存”；不可悄悄假装已保存。
- 胜败结算保存一次且清除续局，显示角色、波次、用时、击杀、伤害、最终构筑；同角色
  再来一局重置所有临时效果。

## §10 技术与交付约束

- 实现地点固定为本项目根目录；应用源码直接放 `src/`、资源放 `public/assets/`，
  不另建其他工作区。
- 首选 TypeScript + Vite + Phaser 3；DOM 菜单使用 Tailwind CSS + daisyUI 5。安装兼容
  稳定版本并锁定依赖，具体版本由实际开发时确认；不在设计文档虚构已安装版本。
- 单页静态前端，无后端、无数据库、无 API Key；打包后不需要联网获取模型、字体或素材。
- 战斗状态与规则独立于渲染组件；角色、敌人、波次与强化采用数据配置，交互不按帧数计时；
  固定逻辑步长，卡顿时限制追帧。
- 提供 `npm run dev`、`npm run build`、`npm run typecheck`、`npm run lint`、
  `npm run test`；测试采用 Vitest，浏览器验证按现有 agent-browser skill。
- 当前引擎 `ports` 返回 5343–5347，主服务用 5343 并启用严格端口；启动前重新查引擎
  分配，不静默切到相邻项目端口。
- 开发测试入口可提供仅开发环境的固定种子/场景参数与只读状态快照，便于断言；生产页面
  不带跳关、无敌或直接改完成状态入口。
- 像素资源属于游戏源文件，必须由 Claude CLI 的开发流程产出并实际载入；Codex 不替其
  制作成品游戏代码。
- 测试不能仅依赖调试接口：关键通关、选卡、暂停、续局须在真实键盘交互中走通。
