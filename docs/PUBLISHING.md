# GitHub 发布方式

公开仓库只包含游戏、可重复构建工具、人类文档与设计稿。当前工作分支保留完整本地开发历史；公开的 `main` 来自本地 `github-main` 干净快照，二者不是同一套提交历史。

## 发布说明（V0.3，2026-10-26）

- 版本内容：18 波、波间商店、U/I 自由技能、永久道具 I01–I24、药剂 P01–P08、宝箱、精英核心 E01–E08、合成 R01–R06、48 种海克斯；本次已接入V0.3星盘熔炉美术；源图、生产图、构建工具与截图见`docs/art/`。
- 分享产物：`output/share/game/像素回响.html`（资源全内联，不设体积硬上限）与 `output/share/像素回响-轻量游戏包.zip`（本轮不设体积硬上限）；分享包只含白名单文件，不含开发入口、凭证、`.git/`、`.claude/`、`.memory/`、截图全集或未跟踪历史截图。
- 构建不依赖联网字体、素材或模型；前端为单页静态文件。
- **未验证项**：US-066 人工 18 波普通构筑试玩与 US-051 性能/泄漏检测由用户于 2026-10-25 明确跳过，均未执行。发布说明不得写成“全部 64 项通过”“真人已通关”“V0.2 已达到 50 FPS 或无泄漏”。

不公开本地凭据/配置、记忆、浏览器数据、AI 原始日志、自动试玩轨迹、无关企业材料生成脚本。开发文档提到的早期提交号是本地审计标识，不一定能在公开仓库查询。

先检查并提交本地需要发布的游戏/文档改动，再执行：

```bash
python3 tools/release/publish_snapshot.py
git push origin github-main:main
```

脚本使用独立 Git index，不修改当前分支或工作区，不自行联网或推送。公开分支后续以原公开提交为父节点更新，正常推送即可，不需要强制推送。

不要直接把本地完整开发分支推上公开仓库，也不要使用 `git push --mirror` 或 `git push --all`。
