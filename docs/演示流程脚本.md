# 演示流程脚本

面向人工演示与浏览器验收的逐步操作脚本。所有步骤都使用真实键盘事件；开发入口只用于
固定种子/场景复现，不作为正常通关证据。

## 0. 准备

```bash
npm install
npm run typecheck
npm run lint
npm run test
npm run build          # 产出 dist/ 静态构建
npm run dev -- --port 5343 --strictPort
```

打开 <http://localhost:5343/>。端口被占用时 Vite 会直接失败，不会静默换端口。

质量命令也可分开执行；交付前四条必须全部通过：

| 命令 | 预期 |
| --- | --- |
| `npm run typecheck` | 无输出、退出码 0 |
| `npm run lint` | 无输出、退出码 0 |
| `npm run test` | 全部用例通过 |
| `npm run build` | 生成 `dist/index.html`、`dist/assets/` |

## 1. 主菜单与选角

1. 页面打开后主菜单可见，开始按钮默认获得焦点。
2. 按 `Enter`（或 `Space`）进入选角。
3. 用 `A/D` 或 `←/→` 在维什戴尔 / 阿米娅 / 塞雷娅 / 缪尔赛思之间移动焦点；
   卡片显示定位、属性、J/K/L 与被动摘要。
4. 按 `Enter` 以选中角色开局。3 秒倒计时后进入第 1 波。

可选：主菜单的「帮助」「设置」可用方向键选择、`Enter` 进入，`Esc` 返回；设置里可
静音、关闭屏震、减少动态效果并重绑战斗键位。

## 2. 战斗基础（四角色通用）

| 按键 | 演示动作 |
| --- | --- |
| `W A S D` | 八方向移动，对角线速度归一化；顶墙仍可转身 |
| `J`（可按住） | 沿当前面向持续普通攻击，可空射 |
| `K` | 角色战术技能，按下触发一次 |
| `L` | 角色招牌技能，按下触发一次 |
| `Space` | 按移动方向闪避；前 0.15 秒无敌，冷却 3 秒 |
| `Tab` | 切换前方扇区内提示目标，不改变面向 |
| `Esc` | 暂停 |

观察 HUD：顶部依次显示目标、生命/护盾、波次/等级/经验/击杀、闪避、角色资源；底部
技能条显示 J/K/L 就绪、冷却、生效或锁定状态。

## 3. 角色差异演示

- **维什戴尔**：`J` 榴弹溅射并留下余震；`K` 召唤魂灵标记敌人；`L` 爆裂黎明连续
  强化弹，HUD 显示剩余弹药。
- **阿米娅**：`J` 直线术式，命中累计情绪吸收；`K` 精神爆发多段术式；`L` 奇美拉把
  J/K 改为真实伤害并增伤，结束后短暂虚弱。
- **塞雷娅**：`J` 盾击面前扇区并击退；`K` 急救治疗并获得护盾；`L` 钙质化领域减速
  敌人、提升法伤并持续回复自身。
- **缪尔赛思**：`J` 水弹；`K` 在近战/远程流形间切换或重建；`L` 近战拉拽眩晕、
  远程刷新副本并束缚。远程副本与主流形共享战场。

## 4. 升级、强化与波间

1. 击杀敌人掉落经验球，吸取后升级；战斗冻结并出现三张强化卡。
2. `A/D` 或 `1/2/3` 移动焦点，`Enter` 确认；`R` 使用本局剩余重抽次数（默认 2 次）。
3. 卡片显示名称、稀有度、效果、层数上限与适用技能；确认后立即生效。
4. 第 3/6 波清空后额外出现机制三选一；第 9 波为双阶段 Boss。
5. 波间显示补给信息并回复 15% 最大生命，`Enter` 进入下一波。

## 5. 暂停、设置与结算

1. 战斗中按 `Esc` 暂停；面板提供继续 / 帮助 / 设置 / 返回选角。
2. 暂停期间敌人、弹体、冷却与波次计时全部冻结；`Enter` 或 `Esc` 继续。
3. 死亡或击败 Boss 后显示结算面板：本局成绩、最终构筑与最近 10 局记录。
4. 结算面板可用方向键选择「再来一局」「返回选角」「查看记录」，`Enter` 确认。
5. 返回选角后重新选人开局；设置与键位保留。

## 6. 续局与存档演示

1. 在波初、升级三选一或选卡后的安全检查点刷新页面。
2. 主菜单出现「继续试炼」并默认聚焦，`Enter` 恢复本局；恢复后先暂停，`Enter` 明确继续。
3. 损坏或版本不匹配的存档会显示提示，并允许键盘确认清除。

## 7. 开发场景复现（仅开发环境）

```text
?dev=1&seed=20261020&character=amiya&wave=5&enemies=chaser:3,shooter:2&upgrades=W01,W02
```

- `seed` 固定强化随机序列；`character` 指定角色并跳过菜单/选角；
- `wave` 指定起始波（1–9）；`enemies` 覆盖起始波名册；`upgrades` 开局授予强化；
- `perf=1` 进入隔离性能场景（见下一节），不会进入正常波次流程。

只读状态可通过 `window.__PIXEL_ECHO_DEV__.getSnapshot()` 读取；该桥在开发环境安装，
生产构建不包含。生产页面没有跳关、无敌或修改完成状态的入口。

## 8. 性能与重开泄漏检查（由 Validator 执行）

前置：`npm run dev -- --port 5343 --strictPort` 已运行。

```bash
# 一条命令完成 60 秒帧率采样 + 5 次重开泄漏比较，并写记录与截图
npm run perf
# 等价于 node tools/perf/perf-check.mjs
```

脚本使用 agent-browser 的工程专属会话与完整 CDP URL：

```bash
BROWSER_PY=.claude/skills/agent-browser-skill/scripts/browser.py
WS_URL=$(python3 "$BROWSER_PY" ensure)
AB_SESSION=$(python3 "$BROWSER_PY" session)
agent-browser --session "$AB_SESSION" --cdp "$WS_URL" open "http://localhost:5343/?dev=1&perf=1&character=muelsyse&seed=20261020&upgrades=M01"
```

检查内容：

- 隔离场景同屏维持 **80 敌人 / 40 敌弹 / 3 流形**（主流形 + 2 副本；工具 URL
  带 `upgrades=M01` 使副本上限为 2），页面内 rAF 采样 60 秒，平均 **≥50 FPS**；
- 经真实 UI（`Esc` 暂停 → 返回选角 → `Enter` 确认）连续重开 **5 局**，比较：
  - DOM `window` / `document` / `canvas` 输入监听总数；
  - 存活 Phaser 实例数、画布数、活跃场景数与设置订阅数；
  - 场景 keydown/keyup、游戏 blur、场景 shutdown 监听数；
  - 显示对象、物理体、补间与计时器数量；
  - 每局重新恢复到 80/40/3 的规格实体数。
- 记录写入 `docs/perf-runs/perf-<时间戳>.json`，截图写入 `screenshots/perf/`；
  退出码 0 表示全部通过。采样期间保持页面在前台，后台标签页会节流 rAF，
  脚本会把 `visibility` 写入记录并判失败。

建议同时保存 agent-browser 快照或截图作为浏览器验收证据（文件名
`validator-us-026b-pass-<序号>.png`）。

## 9. 演示结束

1. `Ctrl+C` 停止开发服务；需要停止本工程浏览器时运行
   `python3 "$BROWSER_PY" stop`。
2. 交付物：源码、`public/assets/` 自制资源、`dist/` 构建产物、README、
   `docs/素材来源说明.md`、本脚本与最近一次性能记录。
