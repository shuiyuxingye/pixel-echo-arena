# 演示流程脚本

面向人工演示与浏览器验收的逐步操作脚本，对应 **V0.2 逻辑优先占位版**（18 波、波间商店、
自由技能、道具/药剂、宝箱、精英核心、合成与 48 种海克斯）。所有步骤都使用真实键盘事件；
开发入口只用于固定种子/场景复现，不作为正常通关证据。

> **验收边界**：US-066 人工 18 波普通构筑试玩与 US-051 性能/泄漏检测已由用户于
> 2026-10-25 明确跳过且未验证。本脚本不重启这两项，也不把跳过写成通过。

## 0. 准备

```bash
npm install
npm run typecheck
npm run lint
npm run test
npm run build          # 产出 dist/ 静态构建
npm run build:share    # 产出单文件分享 HTML 与构建报告
python3 tools/docs/package_delivery.py   # 产出游戏 ZIP 与文档 ZIP
npm run dev -- --port 5343 --strictPort
```

打开 <http://localhost:5343/>。端口被占用时 Vite 会直接失败，不会静默换端口。

| 命令 | 预期 |
| --- | --- |
| `npm run typecheck` | 无输出、退出码 0 |
| `npm run lint` | 无输出、退出码 0 |
| `npm run test` | 全部用例通过 |
| `npm run build` | 生成 `dist/index.html`、`dist/assets/` |
| `npm run build:share` | `output/share/game/像素回响.html`，单 HTML ≤8MB、资源全内联 |
| `package_delivery.py` | 游戏 ZIP ≤3MB；ZIP 仅含白名单文件 |

分享包验收可离线进行：断网后双击 `output/share/game/像素回响.html`，或解压
`output/share/像素回响-轻量游戏包.zip` 后双击其中的 HTML。

## 1. 主菜单与选角

1. 页面打开后主菜单可见，开始按钮默认获得焦点；标题为「像素回响：四人试炼」。
2. 按 `Enter`（或 `Space`）进入选角。
3. 用 `A/D` 或 `←/→` 在爆破手 / 术士 / 骑士 / 战术家之间移动焦点；
   卡片显示定位、属性、J/K/L 与被动摘要。
4. 按 `Enter` 以选中角色开局。3 秒倒计时后进入第 1 波。

可选：主菜单的「帮助」「设置」可用方向键选择、`Enter` 进入，`Esc` 返回；设置里可
静音、关闭屏震、减少动态效果并重绑战斗键位。

## 2. 战斗基础（四角色通用）

| 按键 | 演示动作 |
| --- | --- |
| `W A S D` | 八方向移动，对角线速度归一化；顶墙仍可转身 |
| `J`（可按住） | 沿当前面向持续普通攻击，可空射 |
| `K` | 角色战术技能，按下触发一次 |
| `L` | 角色招牌技能，按下触发一次 |
| `U` / `I` | 自由技能槽；在商店购买装备后可用，各自独立冷却 |
| `Space` | 按移动方向闪避；前 0.15 秒无敌，冷却 3 秒 |
| `Tab` | 切换前方扇区内提示目标，不改变面向 |
| `B` | 打开/关闭构筑面板；打开时暂停，关闭后恢复 |
| `Esc` | 暂停 |

观察 HUD：顶部显示波次/倒计时/金币；左侧生命/护盾/经验；底部 J/K/L/U/I 与闪避冷却。
普通敌人受伤后短暂显示血条，精英与 Boss 保留名称/阶段标签。

## 3. 角色差异演示

- **爆破手**：`J` 榴弹溅射并留下余震；`K` 召唤魂灵标记敌人；`L` 爆裂黎明连续
  强化弹，HUD 显示剩余弹药。
- **术士**：`J` 直线术式，命中累计情绪吸收；`K` 精神爆发多段术式；`L` 奇美拉把
  J/K 改为真实伤害并增伤，结束后短暂虚弱。
- **骑士**：`J` 盾击面前扇区并击退；`K` 急救治疗并获得护盾；`L` 钙质化领域减速
  敌人、提升法伤并持续回复自身。
- **战术家**：`J` 水弹；`K` 在近战/远程流形间切换或重建；`L` 近战拉拽眩晕、
  远程刷新副本并束缚。远程副本与主流形共享战场。

角色、怪物、召唤物与技能区域使用圆形、色块、线段、扇区或短标签表示；本轮美术为
后续单独迭代，演示只需确认可分辨、方向与命中范围一致。

## 4. 升级、海克斯与波末奖励

1. 击杀敌人掉落经验球，吸取后升级；战斗冻结并出现三选一。
2. 海克斯三选一在 **2/4/6/8/10/12/14 级**出现，共 7 次；其他等级只给基础成长。
3. `A/D` 或 `1/2/3` 移动焦点，`Enter` 确认；`R` 使用本局剩余重抽次数（默认 2 次）。
4. 卡片显示名称、品质、效果、前置与叠层状态；确认后立即生效。
5. 波末按固定顺序处理奖励：宝箱资格 → 精英核心资格 → 升级/海克斯 → 商店。
   - 宝箱在 2/5/8/11/14/17 波出现，战斗中打破只累积“战利品资格”，波末两件选一。
   - 第 6/9/12/15 波精英被击败后，波末核心三选一。
   - 每份奖励面板显示剩余待领取数量；放弃也会记录，不重复出现。
6. 第 1–17 波奖励处理完后进入商店。

## 5. 商店演示

第 1–17 波结束进入商店，没有倒计时。货架 5 格：3 件永久道具、1 个自由技能、
1 种轮换药剂；旁边常驻 P01 应急药剂。

| 按键 | 行为 |
| --- | --- |
| 方向键 / ↑↓ | 移动焦点 |
| `Enter` | 第一次进入购买/替换确认，第二次确认；长按不重复买 |
| `R` | 重抽货架（收费，费用随本商店重抽次数上升） |
| `F` | 锁定当前格，免费保留 1 格到下个商店 |
| `Tab` | 切换「货架 / 装备 / 配方」三页 |
| `空格` | 准备下一波 |

演示要点：

1. 选中商品后同屏显示收益与代价，以及购买后的属性与金币变化。
2. 装备页出售永久道具，按实付金币 40% 向下取整回收；免费奖励道具售价 0。
3. 配方页追踪 1 条配方，缺件显示名称与进度；材料各扣 1 层并支付手续费后合成，
   确认前显示净变化，失败不扣钱。
4. 购买自由技能后装入 U 或 I 槽；再次购买可升级或替换，替换会回收旧技能。
5. 药剂 P01–P08：立即治疗或给下一波增益/代价，有单波购买上限，波末清除。

## 6. 暂停、构筑、设置与结算

1. 战斗中按 `Esc` 暂停；面板提供继续 / 帮助 / 设置 / 返回选角。
2. 暂停期间敌人、弹体、冷却与波次计时全部冻结；`Enter` 或 `Esc` 继续。
3. 按 `B` 打开构筑面板：按来源分组（永久道具 / 临时饮剂 / 核心 / 配方成品 / 海克斯），
   显示净属性；↑↓ 或 PgUp/PgDn 滚动，Home/End 跳转；`B` 或 `Esc` 关闭并恢复战斗。
4. 死亡或击败第 18 波 Boss 后显示结算面板：本局成绩、最终构筑与最近 10 局记录。
5. 结算面板可用方向键选择「再来一局」「返回选角」「查看记录」，`Enter` 确认。

## 7. 续局与存档演示

1. 在波初、升级三选一、波末奖励或商店等安全检查点刷新页面。
2. 主菜单出现「继续试炼」并默认聚焦，`Enter` 恢复本局；恢复后先暂停，`Enter` 明确继续。
3. 损坏或版本不匹配的存档会显示提示，并允许键盘确认清除。
4. V2 存档使用独立存储空间；V0.1 的构筑、成绩与 9 波进行中进度不会导入。

## 8. 开发场景复现（仅开发环境）

```text
?dev=1&seed=20261020&character=amiya&wave=5&enemies=blob:3,spitter:2&hexes=H01,H02
```

- `seed` 固定本局随机序列；`character` 指定角色并跳过菜单/选角；
- `wave` 指定起始波（1–18）；`enemies` 覆盖起始波名册，格式 `id:数量`；
- `hexes` 开局授予海克斯；`items` 预置永久道具（重复 ID 叠层）；
- `cores` 预置精英核心；`crafted` 预置合成成品；
- `shopOps` 在第一个商店执行购买/出售；`shopPotion` 指定轮换药剂；
- `craft` 指定波间合成面板配方；`track` 开局追踪配方；
- `gold` 预置金币；`maxHealth`、`damageTaken`、`waveSpeed`、`eliteOnly` 用于受控场景；
- `perf=1` 进入隔离性能场景；`triggerDemo=1` 运行只读触发链演示。

完整参数与边界见 `src/game/dev-scenario.ts` 文件头注释。只读状态可通过
`window.__PIXEL_ECHO_DEV__.getSnapshot()` 读取；该桥只在开发环境安装，生产构建不包含。
生产页面没有跳关、无敌或修改完成状态的入口。
