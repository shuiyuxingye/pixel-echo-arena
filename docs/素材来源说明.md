# 素材来源说明

本项目的全部像素资源均为**项目内自制**，由仓库中的生成脚本产出，不包含任何第三方
图片、字体、音频或运行时网络请求。

## 生成方式

```bash
npm run assets
# 等价于 node tools/generate-assets.mjs
```

- 生成器只依赖 Node 内置 `node:zlib` 与 `node:fs`，没有第三方图形库。
- PNG 由脚本直接编码（RGBA、8 bit、无外部元数据），同一 Node 版本下输出稳定。
- 生成结果作为游戏源文件提交到 `public/assets/`；构建与运行时不重新生成、不下载。
- 人物造型参考 `docs/references/wisadel-chibi-reference.png`（用户提供的参考图），
  由开发流程按 Q 版比例重绘，不复用参考图像素；角色视觉验收标准见
  `docs/character-art-direction.md`。

人物精灵表布局（`src/game/player-art.ts`）：

- 每帧 64×64；行 0–3 为下 / 右 / 上 / 左，行 4 为八向施法指向帧；
- 列 0–1 待机、2–5 行走、6 攻击、7 受击；
- 碰撞半径固定 12，不随 Q 版大头轮廓扩大。

## 音频

游戏音效由 `src/game/audio.ts` 在浏览器内用 Web Audio 振荡器实时合成，没有音频文件，
也不请求外部音频资源。

## 字体与界面

DOM 菜单使用 Tailwind CSS + daisyUI 5 的本地打包样式；Phaser 内文字使用系统等宽字体
（`monospace`），不加载网络字体。

## 许可与来源声明

- 上述资源与生成脚本均在本仓库内创建，随本项目代码一同交付。
- 未使用第三方美术素材、素材站下载包、商业字体或 AI 生成的外部图片。
- 参考图仅用于造型方向的人工比对，不参与构建，也不作为运行时资源。
