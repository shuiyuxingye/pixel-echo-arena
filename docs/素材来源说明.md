# V0.3 素材来源与生产清单

本次为星盘熔炉美术迭代。人物身份参考用户提供的《明日方舟》Q版方向与项目此前概念图；生产源图由内置ImageGen生成，再在项目内做透明图集切分、最近邻像素整理、脚底对齐与动画装配。不是官方原游戏精灵，也未引入素材站下载包。

- 原画与图集源文件：`art/source/`，11张PNG。
- 生产贴图：`public/assets/art/`；映射为`src/game/art-manifest.ts`。
- 素材生产：`tools/art/png.mjs`、`tools/art/build-art.mjs`；无外部图像处理依赖，不需要运行时调用模型。
- 旧生成器：`tools/generate-assets.mjs`，保留V0.2资源以便回溯；当前运行入口读新的art目录。
- 图集、规格、复用关系与接线清单见[美术说明](art/README.md)，提示词见[生成记录](art/prompts.md)。

```bash
npm run art:build
npm run build:share
```

四角色帧尺寸96×96，表864×480，四向动作与八向施法槽沿用原接口；脚底y=92、世界碰撞半径12不变。
八种普通怪有独立外形，幼虫和Boss另有贴图；精英沿用对应怪物形象的暖色材质与身份标记。68枚基础图标覆盖商品、药剂、自由技能、核心、配方与通用动作；海克斯复用相应机制图标。四类16帧特效负责爆破、冰晶、水涡和奥术，伤害/预警范围仍由原规则驱动。

音效仍由Web Audio振荡器合成，无下载音频；界面使用本地Tailwind/daisyUI与系统字体。第三方软件许可见分享包`THIRD_PARTY_NOTICES.txt`。

角色为非官方同人参考方向，未声称获得原作角色的商用授权。生成图、源图与代码随本项目交付，不上传本机密钥、账号数据或AI运行日志。
