# 人类文档入口

如果你只想玩游戏，从游戏说明书开始，不需要阅读自动开发日志。

| 读者 | 文档 | 用途 |
| --- | --- | --- |
| 玩家 | [游戏说明书](01-游戏说明书.md) | 上手、键位、四角色、强化、波次与续局 |
| 分享者 | [分享与启动指南](02-分享与启动指南.md) | 最小包、离线启动、存档与发包注意事项 |
| 接手维护者 | [项目现状与维护指南](03-项目现状与维护指南.md) | 当前功能、验证事实、代码入口和维护方法 |

图示源文件位于 [figures/](figures/)，均为 SVG；人物图取自本游戏实际精灵并转为矢量像素展示。HUD 与流程图是说明性示意，不冒充运行截图。

PDF 在项目 `output/pdf/`；分享版在 `output/share/`。开发过程文档保留在原位置，没有被删除。
