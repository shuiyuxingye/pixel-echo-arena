# 分享与启动指南
## 发给朋友，只发游戏包

分享版的运行入口是 **像素回响.html**。它把生产 JavaScript、样式和游戏图片放进同一个文件，接收者不需要 Node、Python、Claude、API Key 或本地服务器。当前分享版是 **V0.3星盘熔炉美术版**：保留18波、商店和完整构筑，角色、怪物、场景与技能/道具贴图已内联，不需额外下载素材。

![分享包结构与启动路径](figures/11-share.svg)

## 接收者怎么打开

1. 将 ZIP 下载到本机并解压，不要在聊天软件的附件预览器里运行。
2. 双击“像素回响.html”，或右键选择浏览器打开。
3. 页面出现主菜单后按 Enter，选择角色开始。
4. 如果浏览器阻止本地脚本或存储，换普通浏览器窗口；不要为了运行游戏关闭系统安全保护。

**只打开游戏，不要运行开发命令。**分享包不包含 AI 工程工具，也不需要登录模型服务。

游戏包与图文文档包分开交付。只想快速试玩，发轻量游戏包；想完整了解玩法，再附游戏说明书 Markdown。V0.2 图文包包含 Markdown 与 V0.1 SVG 插图，**不含已过期的 V0.1 PDF**；MD 与 SVG 用于后续修改手册，不是运行依赖。

# 存档不是游戏文件的一部分

![本地浏览器保存与分享边界](figures/10-save.svg)

## 对接收者的提醒

- 设置、键位、续局和成绩保存在浏览器本机存储中，不会写回 HTML。
- 同一个文件换浏览器或换位置后，可能看不到原存档；把常用游戏文件留在固定文件夹里。
- 隐私窗口、浏览器清理、存储权限限制都可能影响保存；不要把续玩当作跨设备云存档。
- 更换分享版之前先保留旧 HTML；当前游戏没有“导出/导入存档”按钮。

## 发出之前

只打包运行成品与必要说明。不要把 `node_modules/`、`.git/`、`.claude/`、`.memory/`、测试日志、截图全集、个人配置和浏览器 profile 一并发送。

角色形象参考《明日方舟》，参考图由用户提供，游戏像素资源由本项目代码绘制。分享包用于个人试玩；本项目没有提供这些角色的公开商用授权。第三方软件许可随游戏包的 `THIRD_PARTY_NOTICES.txt` 保留。

# 如果你是项目维护者

## 从源代码重新制作分享版

需要 Node.js 24 或更高版本，并进入项目目录：

```bash
npm install
npm run build:share
python3 tools/docs/package_delivery.py
```

生产网页输出到 `dist/`；单文件分享版输出到 `output/share/game/像素回响.html`；游戏 ZIP 与文档 ZIP 由打包脚本输出到 `output/share/`。三者用途不同：`dist/` 用于静态服务器，单文件版用于本机双击打开，ZIP 用于分发。分享包只包含白名单文件，不含 `.git/`、`.claude/`、`.memory/`、`node_modules/`、截图全集与开发入口。

## 原始开发版怎么启动

```bash
npm run dev -- --port 5343 --strictPort
```

打开 `http://localhost:5343/`。若本工程服务已运行，直接打开即可；端口被其他工程占用时先确认归属，不要随意杀掉别人的服务。

## 分享版验证范围

V0.2 单文件版由独立 Validator 在断网环境中以 `file://` 打开，确认主菜单、选角、进入战斗、占位或现有资源正常显示与文件体积；本节不代替 Validator 的结论。

**首次打开仍请人工检查 WASD 移动、J 攻击和 Esc 暂停。**字母键自动化未正确传递键位，聊天内置浏览器也不支持 file://，所以没有把原生键盘兼容性记录为全部通过。具体范围见 `output/share/build-report.json`。

**用户已明确跳过的检查**：

- US-066 人工 18 波普通构筑试玩：未执行，不视为通关验证；
- US-051 性能/泄漏检测：未运行 60 秒压力与 5 次重开检查，不宣称达到 50 FPS 或无泄漏。

制作分享包不会重新执行这两项，也不把跳过写成通过。
