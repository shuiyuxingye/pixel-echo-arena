# 像素回响：四人试炼
## 游戏说明书

**四名角色，一套键盘，18 波挑战。**

你操控一名 Q 版像素角色，在俯视竞技场里移动、攻击、闪避；击败敌人获得经验，用海克斯与商店构筑自己的打法。第 18 波是最终 Boss。

![当前四角色实际选角界面](../art/screenshots/selection.png)

这是一款桌面浏览器单人动作肉鸽原型。角色形象参考《明日方舟》，技能经过适合实时动作玩法的改编。本手册介绍的是这个游戏的实际规则，不是原作角色攻略。

**先记三个动作**：WASD 移动，按住 J 攻击，空格闪避。

版本0.3（星盘熔炉美术版）· 内容核对日期2026-10-26 · 建议横屏、键盘与有声环境

> **V0.1 与 V0.2 的差异**：V0.1 是 9 波、24 种强化的旧基线；V0.2 改为 **18 波**（第 18 波唯一 Boss）、**第 1–17 波结束进入商店**、等级上限 15、48 种海克斯，并加入自由技能 U/I、永久道具、药剂、宝箱、精英核心与六条合成配方。
>
> **画面说明**：V0.3已补全角色、怪物、场景与技能/道具美术；部分SVG仍是旧版规则示意，当前画面以实际截图为准。

>
> **验收边界**：US-066 人工 18 波普通构筑试玩与 US-051 性能/泄漏检测已由用户明确跳过且未验证。本手册不宣称真人已通关、不宣称达到 50 FPS 或无泄漏。

# 01｜三分钟开始第一局

1. 下载并解压分享包，双击 **像素回响.html**，用浏览器打开。
2. 按 Enter 开始，用方向键或 WASD 选择角色，再按 Enter 确认。
3. 等待 3 秒倒计时。先移动，再沿面向按住 J 攻击，不要站在敌群中不动。
4. 击杀敌人掉落经验，达到海克斯等级时选一张三选一；波末进入商店，买完按空格准备下一波。
5. 第 18 波击败 Boss 后结算；生命归零也会结束本局。

## 默认键位

![移动、技能、闪避和界面操作键位图](figures/03-keyboard.svg)

菜单通常用方向键或 W/S 移动焦点，Enter 确认。战斗键可以在设置里重绑；手册中的 J/K/L/U/I 指默认键位。U/I 是商店购买的自由技能槽，各自独立冷却；B 打开构筑面板。切换输入法后无响应时，先切回英文输入并点一下游戏区域。

# 02｜方向，比锁定更重要

![八向移动和面向施法规则示意](figures/04-facing.svg)

- W/A/S/D 可组合成八向移动，斜着走不会更快。松开后，保留最后面向。
- J 和定向技能朝当前面向释放；允许空射。连射中转身只影响后面射出的弹体。
- Tab 只是切换前方的目标提示，不会替你转身或自动瞄准背后的敌人。
- 静止时闪避沿最后面向。闪避持续 0.18 秒，前 0.15 秒无敌，冷却 3 秒，不能穿墙。
- 自身治疗、领域与变身按自身生效；召唤物会自行选择目标。

![战斗画面的信息分区示意，并非游戏截图](figures/05-hud.svg)

**先看生命与护盾，再看技能冷却。**按 B 打开构筑面板查看来源分组与净属性；下方技能条显示当前键位和就绪状态。切到别的窗口会自动暂停，返回后需明确继续。

# 03｜远程角色：爆破与术法

![爆破手和术士的实际精灵与打法](figures/06-ranged.svg)

## 爆破手：用标记放大爆炸

基础生命 **120**、护甲 **10**。J 是较慢的榴弹：命中后产生溅射，并在 0.35 秒后发生余震。带残影的敌人受到余震时，会额外爆炸并短暂眩晕。

- **K 魂灵之影｜14 秒冷却**：召唤一个持续 12 秒的魂灵，为附近尚未标记的敌人附着残影并减速。
- **L 爆裂黎明｜30 秒冷却**：接下来 6 发榴弹伤害翻倍，溅射半径提高 50%；20 秒未使用的弹药失效，空射也会消耗。
- **打法建议**：先用 K 铺标记，再朝聚集的敌群开火；不要因为大招亮着就停在原地挨打。

## 术士：把握真伤窗口

基础生命 **110**、法抗 **15%**。J 是快速直线术式；每 5 次 J 命中，使 K 的剩余冷却减少 1 秒。

- **K 精神爆发｜9 秒冷却**：0.8 秒内连续发射 6 发术式；每发沿当时面向，结束后有 0.5 秒不能普攻，但仍能移动和闪避。
- **L 奇美拉｜30 秒冷却**：持续 8 秒，J/K 转为真实伤害并增伤 60%；结束后 3 秒减速 25%、不能 K/L。
- **打法建议**：找到安全位置再爆发，提前为虚弱阶段留好撤退方向。这个游戏不会照搬原作的强制退场。

# 04｜防护与召唤角色

![骑士和战术家的实际精灵与打法](figures/07-support.svg)

## 骑士：近身输出，但不是无敌

基础生命 **200**、护甲 **35**、法抗 **10%**。J 是面前 100° 扇区的盾击，范围较短，带击退。

- **K 急救配置｜10 秒冷却**：回复 40 生命，获得 25 护盾，护盾持续 4 秒、不叠加。
- **L 钙质化｜28 秒冷却**：8 秒内自身周围形成领域，每秒回复 8 生命；敌人减速 35%、受到法术伤害提高 30%，盾击附加法伤。
- K 确实恢复生命时，会让 L 剩余冷却减少 2 秒；满血施放不会获得这次回转收益。
- **打法建议**：靠近后用扇面同时打多个敌人，但仍要避开冲锋和密集弹体。

## 战术家：选择流形的工作方式

基础生命 **125**、护甲 **5**、法抗 **10%**。J 发射水弹，开局带一个近战流形。

- **K 塑形｜6 秒冷却**：切换近战/远程形态，保留生命百分比；流形死亡时改为重建。
- **近战流形**：承伤并近身攻击，命中可逐步增加自身攻击与护甲。
- **远程流形**：每 8 次攻击生成一个临时副本，默认最多一个副本；切回近战会移除远程副本。
- **L 浅层非熵适应｜24 秒冷却**：近战形态聚敌并眩晕；远程形态刷新已有副本寿命，攻击附带束缚。主流形不存在时，需要先重建。

# 05｜海克斯不是装备清单，是打法选择

击杀敌人掉落经验，靠近吸取。波次结束会自动吸取剩余经验。等级上限 **15**，从 n 级升到 n+1 级需要 `50+15×(n−1)` 经验；每次升级最大生命增加 5 并回复 5。

![海克斯三选一与键盘确认方式示意（插图沿用 V0.1）](figures/08-upgrades.svg)

## 怎么选

- 海克斯三选一在 **2/4/6/8/10/12/14 级**出现，每局共 7 次；其他等级只给基础成长。
- A/D 或方向键移动焦点，1/2/3 可直接把焦点移到对应卡；**最后仍要 Enter 确认**。
- R 重抽当前三张，每局默认共有 **2 次**，不是每次升级都补满。
- 同一手不会出现重复海克斯；职业池只会出现通用或当前职业的海克斯；已拥有且不可叠层的不会继续出现。
- 银、金、棱彩是海克斯品质，候选权重约为 45%/40%/15%；前置未满足的海克斯不会出现。
- 部分海克斯要求先拥有某个道具、核心或技能，卡片上会写明前置。

## V0.2 的构筑从哪来

一局的强化不再只靠升级：波末宝箱给永久道具，精英给核心三选一，商店卖道具/药剂/自由技能，配方把三件道具合成一件成品。具体见第 11 节。

下面第 08–10 节的 24 张强化表是 **V0.1 历史资料**：V0.2 正常流程不发放这些强化，代码保留它们用于旧存档兼容与开发场景。当前构筑以海克斯、道具、自由技能、核心与配方为准。

## 可以尝试的组合

| 角色 | 组合 | 改变了什么 |
| --- | --- | --- |
| 爆破手 | 二次余震 + 标记传染 | 更频繁触发余震，向周围铺开残影 |
| 术士 | 穿透术式 + 心绪共鸣 | 一发打多个敌人，更快获得技能回转 |
| 骑士 | 回生冲击 + 坚盾反击 | 把治疗与护盾转化为近身输出 |
| 战术家 | 双生流形 + 水镜共鸣 | 增加副本容量，配合补攻增强输出 |

这些是机制搭配建议，不是保证通关的固定配方。没有抽到组合，也可以继续用现有构筑完成这一局。

# 06｜18 波里，你会遇到什么

![波次节奏示意（插图沿用 V0.1 的 9 波版，V0.2 实际为 18 波）](figures/09-waves.svg)

第 1–17 波：清空整波刷怪配额且场内无敌人，或倒计时归零，任一条件达成即可过关。第 18 波没有“时间到即过关”，必须击败 Boss。

- 普通敌人按首次出现波次逐步解锁：团团怪 1、镰足虫 2、喷菇 3、冲锋猪 4、盾壳蟹 5、灯灵 7、爆爆兽 10、巢母 13。
- 精英波为 **6/9/12/15**；只有击败精英才获得精英核心资格。
- 宝箱在 **2/5/8/11/14/17** 波开始 8 秒后出现；打破只累积“战利品资格”，波末再二选一。
- 第 **18** 波是唯一 Boss 波。

| 敌人 | 你应该观察什么 | 应对方向 |
| --- | --- | --- |
| 团团怪 | 直接朝你靠近 | 留移动空间，边拉开边转身攻击 |
| 镰足虫 | 快速绕侧 | 不要只盯正面，注意侧后方 |
| 喷菇 | 停顿后发射孢子弹 | 横向移动，不长时间停在同一射线上 |
| 冲锋猪 | 蓄力后直线冲锋 | 不沿冲锋路线后退，优先向侧面避开 |
| 盾壳蟹 | 慢速挡路，弱点方向有线段/标签 | 绕到弱点方向或用法术/真伤 |
| 灯灵 | 为队友治疗，有治疗对象/范围提示 | 优先打断或集火 |
| 爆爆兽 | 0.9 秒蓄力自爆，可被击杀打断 | 看到蓄力就优先处理 |
| 巢母 | 按次数与同屏上限召幼虫 | 别让它持续召怪 |
| 裂隙炉王 | 第 18 波 Boss，半血后进入第二阶段 | 注意弹幕、锤击、冲锋与增援 |

每波开始有 3 秒倒计时。普通波时长 `30+2×波数` 秒，精英波再加 8 秒。波间恢复最大生命的 **15%**；第 1–17 波处理完奖励后进入商店，按空格准备下一波。生命归零立即结束；与 Boss 同帧死亡按失败处理。

游戏没有局外永久战力成长。重开后重新选择海克斯与商店构筑，保留的是本机设置和成绩记录，不是上一局的战斗增益。

# 07｜暂停、续玩与常见问题

![本地文件、浏览器和存档的关系](figures/10-save.svg)

**Esc 暂停；切换窗口也会自动暂停。**回到页面后按 Enter 明确继续。不要把浏览器仍在显示画面误认为战斗已经恢复。

游戏在波初、波间、海克斯选择和商店等检查点保存。重新打开后，从主菜单选择“继续试炼”；恢复后先暂停，确认后继续。它不是每帧存档，刷新可能回到最近检查点。最近 **10 局**成绩会保存在本机。

| 遇到的情况 | 先这样处理 |
| --- | --- |
| 按键没反应 | 点击游戏区域；退出输入框；切回英文输入；检查是否处于暂停或海克斯选择 |
| 能移动但打不到 | 先转向敌人再 J；Tab 不会改变弹道，射程外不会命中 |
| 没有声音 | 先按一次确认键，再检查游戏静音和系统音量 |
| 找不到以前的存档 | 用原浏览器、原文件位置；不要用隐私窗口。换文件名、移动文件或清除站点数据可能影响存储 |
| 提示不能保存 | 本局仍可玩，但不要依赖续局；改用允许本地存储的普通浏览器窗口 |
| 窗口太小、文字拥挤 | 使用桌面横屏，建议至少 1280×720；先恢复浏览器默认缩放 |

单文件版的本地存储受浏览器对 file:// 的规则影响。分享 HTML 或 ZIP 不会把你的浏览器存档一起发给朋友。

消耗品 P01–P08 不属于永久构筑：P01 是每间商店常驻的应急治疗，P02–P08 是当手轮换药剂，可能立即治疗或给下一波增益/代价，波末清除。

## 商店怎么用

第 1–17 波结束进入商店，没有倒计时；按“准备下一波”才开战。货架有 5 格：3 件永久道具、1 个自由技能、1 种轮换药剂，旁边常驻 P01 应急药剂。

| 按键 | 行为 |
| --- | --- |
| 方向键 / ↑↓ | 移动焦点 |
| Enter | 第一次进入购买或替换确认，第二次确认；长按不会重复买 |
| R | 重抽货架（收费，费用随本商店重抽次数上升） |
| F | 锁定当前格，免费保留 1 格到下个商店 |
| Tab | 切换“货架 / 装备 / 配方”三页 |
| 空格 | 准备下一波 |

- 装备页可出售永久道具，按该件**实际支付金币的 40%** 向下取整回收；免费获得的道具售价为 0。
- 配方页可追踪 1 条配方；缺件会显示名称与进度。材料各扣 1 层、支付手续费后合成，确认前会显示净属性变化。
- 价格随商店波数上升；折扣合并后净折扣最多 35%，最终价格至少 1 金币。
- 金币不足时按钮禁用并显示差额；购买、合成、替换技能都是原子操作，失败不扣钱。

## 战斗内构筑面板

按 **B** 打开，战斗暂停。面板按“永久道具 / 临时饮剂 / 核心 / 配方成品 / 海克斯”等来源分组，并显示当前净属性。↑↓ 或 PgUp/PgDn 滚动，Home/End 跳转；**B 或 Esc** 关闭并继续。
