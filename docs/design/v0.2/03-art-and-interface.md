# V0.2 占位显示与功能界面

状态：**逻辑优先；用户已授权恢复Harness，美术仍延期。**

## 本轮显示边界

- 角色、敌人、召唤物、子弹、宝箱与区域效果先用圆形、矩形、线段、扇区、文字等简单元素表示；直接使用现有 Phaser Graphics/DOM，不制作新的 SVG、人物插画、怪物精灵或动画表。
- 已接入的资源可继续使用，不为换成圆形而回滚已完成代码；也不继续修饰人物表情、盾牌像素、配件或逐帧姿态。
- 画面只需支持操作和验证：玩家与敌人可分辨，本体/主流形/副本标记不同，方向有箭头或线段，弹体/范围与实际命中一致。玩家碰撞半径保持12。
- 怪物种类与行为完整保留；用简形、大小、短标签或线型区分种类，不仅依赖颜色。纯换色不改变属性。
- 精英使用加粗外圈与“精英”文字；Boss显示名称、生命和阶段，半血后更新阶段标签即可，不要求裂甲动画。
- 危险预警与攻击范围仍必须可见并对应实际落点：普通至少0.7秒，精英/Boss至少0.8秒；用范围轮廓加颜色/文字，不做华丽特效。
- 美术母版、像素尺寸、SVG布局和视觉风格都不作为本轮通过条件；原方向保存在 `deferred-art-direction.md`，后续单独安排。

## 商店：功能布局，不复刻设计图

不要求复刻旧SVG的位置、装饰或图标；保留以下信息与键盘交互即可。商品/技能图标可用文字或色块，先把交易和构筑做通。

上方只放金币、生命、下波类型与结算完成状态。中间5件货物，卡片同屏显示价格、收益和代价。选中卡下面显示“购买后的属性与金币”，右侧显示追踪配方缺件。底部常驻U/I与下一波按钮。

- 默认键盘：方向键选卡，Enter购买/确认，R重抽，F锁定，Tab切换“货架/装备/配方”页，空格准备下一波。
- Enter第一次进入购买/替换确认，第二次确认；长按不重复买。药剂允许明确的“再买一个”，仍遵守金币与单波上限。
- 负面属性用下降箭头、明确文字和暖红色共同表达；不能只用颜色，也不能在滚动区藏代价。
- 合成材料缺件直接显示名称与进度；可合成时出现高亮动作，不把合成埋在道具详细页。

## 战斗与结算界面

- 战斗顶部：波数、倒计时、金币；左侧生命/护盾与经验；底部J/K/L/U/I和闪避。用短提示显示“金币+3”“战利品资格+1”，不打断战斗。
- 波末：先展示金币与击杀简报，随后按队列处理宝箱二选一、精英核心三选一、海克斯；每个面板都说明剩余待领取数量。
- 宝箱战斗中只显示破碎与资格增加；不弹道具选项、不立刻增加属性。第18波结束直接结算，无商店按钮。
- 构筑面板用B查看，显示来源分组与净属性；战斗打开时暂停，关闭后明确恢复。界面要把“临时饮剂”“永久道具”“核心”“配方成品”“海克斯”分开，而不是一个越来越长的文字列表。

## 本轮验收

浏览器只检查键盘输入、方向/范围、状态切换、商品正负属性、交易、结算和恢复。截图仅证明功能可见；不做母版相似度、4倍像素截图、逐帧五官或装饰验收。实体数量/命中/伤害仍用实际规则与测试断言，不以占位画面代替逻辑实现。
